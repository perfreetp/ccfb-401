# 林火前线 · Forest Fire Command

一款基于 **TypeScript + PixiJS** 的森林火灾扑救指挥策略推演游戏。玩家需要在网格化火场中完成部署、实时指挥、风向突变应对、火场复盘与批量推演。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的地址（默认 `http://localhost:5173`）。

```bash
npm run build   # TypeScript 检查 + 生产构建
npm run test    # Vitest 单元与集成测试
```

## 核心玩法

### 1. 战役地图

- 5 个递进战区：青松岭、鹰嘴崖、南坡林场、双河、黑风口。
- 每个战区有独立地图种子、初始火点、设施、预算、时限与风场过程。
- 完成推演并达到 2 星以上解锁下一战区。

### 2. 部署编组

- 三类单位：地面扑火队、水罐消防车、救援直升机。
- 单位成本、速度、载水量、射程、开挖速度、探测半径均由配置表驱动。
- 支持手动点选部署、内置战术模板、保存/载入自定义部署方案。

### 3. 实时指挥

- 火按 **风向、风速、坡度、植被、含水率、湿度、气温** 蔓延。
- 地面单位寻路绕开火线与断崖；直升机可跨越地形。
- 行为树自动执行：补水、避险、扑救、开挖隔离带、被困求救、失联。
- 玩家可下达：
  - 拖线开挖隔离带
  - 指定洒水/吊桶投水
  - 点逆火
  - 单单位撤离、全员撤离
  - 暂停与 1×/2×/4× 变速
- 风场事件带提前预警与倒计时，风向突变后火势会立即重新计算。

### 4. 复盘分析

- 自动记录每次推演：过火面积、设施损失、用水量、隔离带、逆火、求救、风变次数。
- 火场过火图、过火面积曲线、关键事件日志与战术建议。
- 历史档案最多保留最近 20 次推演。

### 5. 批量推演

- 复盘页内置 Web Worker 无头推演。
- 同一张地图、同一组随机种子，支持 60/200/400 局/套。
- 可对比内置模板与玩家保存的部署方案。
- 输出均值、中位数、P10–P90、达成率、平均用水量与单位损失。

### 6. 数值配置

- 火行为、单位、植被、地形、战役参数、评分、批量推演全部放在 `src/config/gameConfig.json`。
- 游戏内「数值配置」页可直接修改，改动自动保存到浏览器本地配置。
- 支持导入、导出、恢复默认与完整 JSON 源码编辑。
- 正在进行的推演保留旧参数快照，新推演使用新配置。

### 7. 版本化存档

- 存档 schema 当前为 **v3**。
- 内置迁移链：`v1 → v2 → v3`。
- 支持旧版 localStorage key 自动迁移、JSON 导入导出、内置 v1 旧档示例。
- 未来版本只需追加 `v(n) → v(n+1)` 迁移函数，旧档继续可读。

## 项目结构

```text
src/
  config/           游戏配置表、配置存储与类型
  sim/              地图生成、火势模型、寻路、行为树、推演引擎、批量推演
  render/           PixiJS 地图渲染器
  ui/               应用外壳与五个页面
  save/             版本化存档与迁移链
  strategies/       内置部署模板
  workers/          批量推演 Web Worker
  test/             Vitest 测试
```

## 测试覆盖

- 寻路绕开火线与断崖
- 风向、湿度、坡度、植被对蔓延概率的影响
- 自动补水、避险、求救、隔离带开挖
- 玩家洒水与逆火指令
- 风变预警
- v1/v2 存档迁移
- 批量推演与战役平衡探针

## 本地数据

游戏不使用后端。以下数据保存在当前浏览器：

- 战役进度与历史复盘：`localStorage['lfr.save.v3']`
- 自定义数值配置：`localStorage['lfr.config.v1']`

清理站点数据会删除这些内容，建议通过「存档管理」定期导出。
